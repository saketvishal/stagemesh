# StageMesh 0.6.45

StageMesh 0.6.45 completes the recovery path for responsive evidence invalidated
by the verified-CSS-viewport upgrade.

## Automatic exact-recipe recapture

- A blocked REVIEW-stage task is automatically reconsidered when its invalidated
  capture records a complete loopback server command, routes, and viewports.
- StageMesh replays only that exact candidate-bound recipe. A command containing
  a redacted value, a non-loopback origin, an invalid route, or an invalid
  viewport remains blocked instead of being guessed or expanded.
- Capture stays headless, uses measured CSS viewports, serializes automatic
  replay inside the run process, and leaves no browser process or profile.
- A successful recapture produces a human-decision block with the exact
  `decide-browser` command. It does not call an implementation provider and does
  not treat screenshot generation as visual approval.

## Evidence

Synthetic coverage proves recipe recovery, redacted-command refusal, block
reclassification, and the REVIEW-stage stop before any provider call. Real
Windows acceptance replayed an invalidated recipe through hidden Edge, produced
an exact 360x800 CSS viewport and PNG, and left no browser process or disposable
profile.
