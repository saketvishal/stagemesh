# StageMesh 0.6.52

## Governed planning readiness

Run-window preflight reports a warning for incompatible planning roles.
Starting a fresh plan requires authorized, available, distinct REVIEW commands.
A task with valid accountable approval can reuse its frozen planning evidence.
Governed profile setup selects from available REVIEW commands and refuses
an incompatible explicit assignment.

Existing projects retain their configured provider capabilities and authority.
If the report names a planning role with a missing REVIEW command, configure
that provider for REVIEW or select an eligible, distinct provider for that role.

## PR-only run windows

StageMesh verifies and refreshes the integration baseline before task selection.
Clean, idle checkouts fast-forward safely. Provably dead executions are recovered
in the same window, with their receipts preserved. Live or unknown ownership
holds prevent checkout movement. Preview leaves the checkout and execution
state untouched. Closed issues report as closed even when their bodies retain
an old hold.
