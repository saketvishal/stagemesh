# StageMesh 0.6.7

StageMesh 0.6.7 is a compatible patch release. Publication is established only by the annotated `v0.6.7` tag, its non-prerelease
GitHub release, a successful trusted-publishing workflow, and the resulting immutable PyPI file; these notes alone are not publication.

## Existing-project GitHub admission repair

- `stagemesh init` now adds the safe automatic-admission default to existing GitHub projects that predate the setting, including projects
  that already have a generated or customized `task_sources` list.
- Existing task-source selectors are not replaced or rewritten. An explicit `github.auto_label_unlabeled: false` opt-out remains false.
- Once migrated, open issues carrying ordinary team labels follow the same bounded classification introduced in 0.6.6.
- Required classification without GitHub Issues write authorization remains a readiness blocker, so initialization cannot report ready while
  the same issues will predictably be left out by `run-window`.
- The repair changes no provider authorization, performs no provider calls, and preserves the additive-only labeling and audit boundaries.

## Verification

The candidate includes synthetic regression coverage for the exact existing-project configuration shape, preservation of custom task-source
selectors and explicit opt-out, authenticated classification, write-authorization refusal, queue resynchronization, and run-window admission
guidance.
