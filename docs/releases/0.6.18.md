# StageMesh 0.6.18

StageMesh 0.6.18 is a live-output correction. Publication is established only
by the annotated `v0.6.18` tag, its non-prerelease GitHub release, a successful
trusted-publishing workflow, and the resulting immutable PyPI file; these notes
alone are not publication.

## Compact run-window progress

- Scheduler-capacity progress prints once immediately and then at most once per
  minute instead of emitting every short-lived capacity transition.
- The compact line reports coding and verification occupancy, the current idle
  reason, and only a waiting-task count. Per-task waiting details remain in the
  durable audit trail and final run-window report.
- Task starts and finishes, provider selection and fallback, implementation
  failures, candidates, validation, reviews, integration, PR publication, and
  long-running-step heartbeats remain immediate and flushed.
- `--no-progress` remains fully quiet, and JSON reports remain isolated on
  standard output.

Focused progress tests verify the rate limit, compact waiting summary, event
forwarding, live ledger monitoring, heartbeats, JSON output separation, PR
progress, and retargeted publisher deadlines. Hosted Linux, Windows, and
attribution checks must pass on the exact PR head before merge.

## Boundary

This release does not change Caventra product or research files. The separate
Agy generated-settings correction remains isolated and is not included in
0.6.18; projects without a passing Agy live acceptance should leave that
provider inactive.
