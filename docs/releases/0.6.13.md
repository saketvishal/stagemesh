# StageMesh 0.6.13

StageMesh 0.6.13 is a compatible provider-safety migration patch. Publication is established only by the annotated `v0.6.13` tag, its non-prerelease GitHub release, a successful trusted-publishing workflow, and the resulting immutable PyPI file; these notes alone are not publication.

## Safe provider configuration upgrades

- Fresh installations continue to save the bounded, headless provider defaults introduced in 0.6.12.
- `stagemesh init` now replaces the exact unsafe built-in commands generated by older StageMesh releases, including Grok's former `--always-approve` default.
- The migration is narrow: customized built-in commands, provider plugins, capabilities, authorization, routing, and unrelated configuration remain unchanged.
- Initialization reports which bundled providers were hardened and makes no provider or model calls.
- Invocation-time hardening remains authoritative, so restored or customized legacy commands cannot bypass the runtime browser and desktop isolation boundary.

## Verification boundary

Focused initialization, provider catalog, registry, stage-routing, bootstrap, and command-hardening tests cover fresh projects, exact legacy upgrades, custom-command preservation, idempotence, and zero-call behavior. No live provider or browser was invoked while preparing this patch.
