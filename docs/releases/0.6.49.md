# StageMesh 0.6.49

StageMesh 0.6.49 closes the retained-candidate browser-evidence loop. When an
independent reviewer identifies a missing browser state, StageMesh can reuse the
verified local server recipe to collect bounded headless evidence and resume
review without rerunning implementation.

## What changed

- StageMesh ranks links against the unresolved finding and follows at most three
  relevant same-origin GET routes under the already captured application area.
- It recaptures existing viewports and may open one uniquely declared
  `aria-haspopup="dialog"` control per selected route. It never types, invokes an
  arbitrary selector, navigates off the loopback origin, or opens a visible
  browser.
- The expansion is bound to the retained candidate, source capture, and finding
  digest, limited to 20 total captures, and may run only once for that state.
- A successful capture resumes the existing exact-receipt independent review.
  The completed independent review is the candidate's internal acceptance
  record; a redundant pre-review acceptance artifact is not required.
- A failed expansion is audited and stops as an external dependency instead of
  returning the task to implementation.

## Safety and compatibility

- StageMesh reuses only a non-redacted server command from a verified capture
  and the exact retained candidate worktree.
- Existing candidates, validation results, findings, and review history are
  preserved.
- Non-browser findings, unrelated routes, ambiguous dialog controls, and
  unreplayable capture recipes do not receive automatic expansion.
- Provider selection, independent-review rules, and Caventra application code
  are unchanged.

## Acceptance coverage

Synthetic tests cover route ranking, same-area isolation, exact declared-dialog
selection, one-shot recovery after the generic retry budget is exhausted,
candidate binding, and coordinator ordering. A real installed-browser test
verified hidden mobile and desktop captures of a nested route and its declared
dialog. The focused recovery, evidence-routing, and review suites pass together.
