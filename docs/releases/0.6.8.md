# StageMesh 0.6.8

StageMesh 0.6.8 is a compatible patch release. Publication is established only by the annotated `v0.6.8` tag, its non-prerelease
GitHub release, a successful trusted-publishing workflow, and the resulting immutable PyPI file; these notes alone are not publication.

## Ready-to-runnable contract handoff

- `run-window` now materializes a deterministic task contract before conflict-aware scheduling when an admitted task is safely plannable
  but does not yet have a contract file.
- Contract creation uses the existing project profile and auto-plan validation path, writes only below the project-local StageMesh runtime,
  and records `contract.auto_generated` audit evidence before any provider starts.
- Generated contracts participate in the same resource-conflict checks as explicit contracts; StageMesh does not bypass scope isolation to
  make a ready issue runnable.
- A generation failure remains fail closed with the auto-plan reason and safe next action.
- `run-window --plan` and inventory-style selection remain read-only and do not create contracts.

## Verification

The candidate includes synthetic acceptance proving that a ready task with a missing but plannable contract is materialized, audited, selected,
and executed; conflict-aware scheduling remains intact; and read-only planning remains non-mutating.
