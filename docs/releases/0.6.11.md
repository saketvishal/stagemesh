# StageMesh 0.6.11

StageMesh 0.6.11 is a compatible safety patch. Publication is established only by the annotated `v0.6.11` tag, its non-prerelease GitHub release, a successful trusted-publishing workflow, and the resulting immutable PyPI file; these notes alone are not publication.

## Provider-home capability isolation

- Unattended Grok workers no longer import Claude, Codex, or Cursor skills, rules, agents, MCP servers, hooks, or sessions from the operator's interactive agent homes.
- StageMesh preserves Grok authentication while setting the provider's documented compatibility controls to disabled for every implementation, recovery, planning, and review process.
- Only project-registered capabilities and StageMesh's bounded skill attachments remain eligible for unattended work. This prevents unrelated browser and computer-use skills from opening local skill files or taking control of the desktop.

## Verification

Synthetic contracts cover every external compatibility surface for all three imported agent homes, preservation of authentication/configuration, non-Grok isolation, and all provider launch paths. Local inspection with Grok 1.0.70 confirmed that the compatibility cells and imported Claude browser/computer-use skills become disabled without making a model call.
