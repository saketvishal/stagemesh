# StageMesh 0.6.53

## Governed planning

- Select a planner and an independent challenger from the authorized REVIEW
  pool. Configured role names act as preferences. A fallback planner runs
  only while an eligible independent challenger remains available.
- Keep tasks awaiting fresh planning queued when no independent pair is
  available. Reuse verified current planning evidence and accountable approvals.
- Use the same effective staging baseline for PR-window previews and live
  selection, including retained staging work ahead of the integration branch.

## Planning recovery and decisions

- Preserve StageMesh-generated plans, challenges, and approvals in local
  history when their baseline or contract changes. Keep the original receipts
  in the ledger and require fresh planning and approval on the new identity.
- Serialize approval publication with planning recovery.
- Report outstanding challenge decisions as decisions even when the reviewer
  returns a revision verdict.

Windows CI now exercises governed recovery when a baseline advances and a
preferred challenger is unavailable. The full regression includes the
governance setup suite.
