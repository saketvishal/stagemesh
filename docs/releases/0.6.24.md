# StageMesh 0.6.24

StageMesh 0.6.24 hardens real-provider planning and normal run continuation as
one release, based on adversarial tests and an independent Claude review.

## Exact planning budgets

- Provider-authored planning specs and challenges are fitted against the complete
  8,000-character canonical artifact, not only per-item limits.
- Every finding and planning item is retained. Shortened descriptive text carries
  a visible marker, and shared-prefix items retain distinct identities.
- Required decisions, paths, verdicts, and provider identities are never silently
  shortened or dropped; an artifact that cannot fit without semantic loss receives
  a typed over-budget refusal.
- JSON with duplicate keys, nested duplicate keys, multiple objects, array wrappers,
  or truncated array wrappers fails closed.

## Crash-safe artifact publication

- Planning receipts are durable before artifact publication, so an interrupted
  publication can safely rerun instead of leaving an unverified artifact dead end.
- Artifacts are written and synchronized through a same-directory temporary file,
  then published without overwrite. Unsupported hard-link publication is a typed,
  recoverable failure.

## Normal continuation

- `stagemesh run-window` can infer one unambiguous unfinished labelled scope.
- Repeating `--label` reuses the one unfinished matching scope while ignoring
  irrelevant completed history. Multiple unfinished scopes still fail closed.
- Stale internal scope IDs cannot follow supersession or clearing into a wider run.
- User-facing resume commands carry the GitHub label, including labels beginning
  with a hyphen, spaces, or Unicode; internal scope UUIDs remain machine-only.

## Verification boundary

The candidate is covered by exact canonical-boundary, escape-inflation,
shared-prefix collision, duplicate-key, publication-interruption, restart,
legacy-scope, supersession, ambiguity, and user-command regression tests. Claude
performed two read-only adversarial passes; the second reported no remaining
material finding. Hosted Linux, Windows, attribution, packaging, and protected-main
checks remain required before the release is published.
