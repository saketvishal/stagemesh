# StageMesh 0.6.12

StageMesh 0.6.12 is a compatible provider-isolation safety patch. Publication is established only by the annotated `v0.6.12` tag, its non-prerelease GitHub release, a successful trusted-publishing workflow, and the resulting immutable PyPI file; these notes alone are not publication.

## Unattended provider tool isolation

- Provider command hardening now runs at every invocation, so projects initialized by an older StageMesh release receive the safety boundary after upgrading without rewriting their project configuration.
- Grok no longer runs with `--always-approve`. Its unattended tool surface is reduced to repository file inspection and terminal execution, web search and subagents are disabled, and common Windows desktop/browser launch commands are denied.
- Codex uses an ephemeral noninteractive session and ignores ambient user configuration while preserving command-line capability attachments.
- Claude disables Chrome, session persistence, slash expansion, and ambient MCP configuration. Safe mode is enforced unless StageMesh attaches an explicit validated project capability.
- AGY removes permission bypass, enables its terminal sandbox, and disables slash-command expansion.
- All provider subprocesses receive explicit CI/no-desktop markers in addition to the existing desktop-bridge filtering and Grok external-home isolation.

## Verification boundary

Synthetic command, provider registry, authorization, event, Git identity, and explicit MCP/plugin attachment contracts passed. The installed Codex, Claude, Grok, and AGY CLIs accepted the enforced flags through their local help parsers without a model call. No live provider task or desktop/browser acceptance was run while preparing this patch.
