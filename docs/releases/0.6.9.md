# StageMesh 0.6.9

StageMesh 0.6.9 is a compatible patch release. Publication is established only by the annotated `v0.6.9` tag, its non-prerelease GitHub release, a successful trusted-publishing workflow, and the resulting immutable PyPI file; these notes alone are not publication.

## Provider-plugin activation

- Provider discovery now combines bundled adapters with independently installed Python entry points in the `stagemesh.providers` group.
- Every `stagemesh init` refresh discovers currently installed adapters and merges new entries without overwriting project-owned provider configuration.
- Interactive init clearly distinguishes registered, available, active, and inactive providers, then offers one explicit opt-in to activate all newly available plugins. Scripted setup retains repeatable `--authorize-provider` flags.
- Provider authorization changes are recorded in the audit ledger and initialization still makes no model call.

## GitHub blocked-label reconciliation

- When a GitHub-backed task is actionable again after StageMesh published a blocked outcome, the next owned lifecycle tick removes only the StageMesh-owned `stagemesh:task-blocked` label.
- Cleanup is idempotent, treats an already-absent label as success, records outbound audit evidence, and never changes local task truth because of a GitHub failure.

## Verification

Synthetic acceptance covers external provider entry-point discovery, non-destructive registry refresh, complete one-confirmation activation, authorization audit evidence, blocked-label removal, idempotence, and already-absent labels.
