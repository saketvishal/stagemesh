# StageMesh 0.6.4

StageMesh 0.6.4 is a compatible patch release. Publication is established only by the annotated `v0.6.4` tag, its non-prerelease
GitHub release, a successful trusted-publishing workflow, and the resulting immutable PyPI file; these notes alone are not publication.

## Safe initialization upgrade

- Rerunning `stagemesh init` upgrades only StageMesh's exact generated placeholder profile when the repository now exposes a safely
  detected validation gate.
- An older placeholder in a Python repository now becomes the fixed `stagemesh validation-bootstrap` gate automatically. The first
  task may begin, but it cannot complete until at least one standard-library `unittest` is discovered and all discovered tests pass.
- A newly added conventional test configuration is detected in the same way.
- When no existing command can be detected, interactive setup presents numbered choices to bootstrap basic Python `unittest`
  validation with the first task, enter the project's existing command, or leave setup incomplete. Users do not need to know the
  internal bootstrap command.
- Hand-written profiles, invalid profiles, and already-real profiles remain unchanged. If no real gate can be detected, the existing
  placeholder also remains unchanged and init continues to explain what is needed.
- Initialization still does not execute tests or invoke providers.

## Verification

The candidate includes focused synthetic acceptance for placeholder migration after Python source appears, existing profile preservation,
idempotent initialization, installed-runtime behavior, package version consistency, and documentation integrity.
