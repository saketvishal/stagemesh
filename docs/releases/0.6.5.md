# StageMesh 0.6.5

StageMesh 0.6.5 is a compatible patch release. Publication is established only by the annotated `v0.6.5` tag, its non-prerelease
GitHub release, a successful trusted-publishing workflow, and the resulting immutable PyPI file; these notes alone are not publication.

## Actionable task admission

- `stagemesh run-window` preserves the exact cached GitHub eligibility reason instead of reporting only “source no longer eligible.”
- Missing required labels, excluded or blocking labels, closed issues, objective roots, validation errors, and incomplete source sync each
  receive a bounded explanation and safe next action.
- The final `next:` line repeats the single applicable action when every parked task has the same cause. Multiple distinct causes direct
  the operator to the individually listed actions rather than inventing one fix.
- Missing `stagemesh:ready` guidance explains both manual labeling and automatic classification of an unlabeled issue through
  `stagemesh init` with GitHub Issues write access.
- Selection remains fail closed: the change explains admission decisions but does not make an ineligible issue runnable or change labels.

## Verification

The candidate includes focused output acceptance plus the complete run-window, GitHub task-source, and admission-diagnosis regression
files. It preserves the empty-backlog message when there are genuinely no tasks to explain.
