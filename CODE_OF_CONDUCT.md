# Code of Conduct

StageMesh is an open-source engineering project. Participation should be professional, constructive, and focused on improving the software and its community.

## Expected behavior

Participants should:

- discuss technical disagreements with evidence and respect;
- critique ideas and implementations rather than people;
- provide enough context for others to reproduce bugs and evaluate proposals;
- respect security, privacy, licensing, and project boundaries;
- avoid harassment, threats, discrimination, doxxing, or deliberately disruptive behavior;
- give contributors reasonable credit for their work.

## Unacceptable behavior

Harassment, discriminatory conduct, personal attacks, publication of private information without permission, malicious disruption, or knowingly unsafe security behavior is not acceptable in project spaces.

## Scope

This applies to repository issues, pull requests, reviews, discussions, documentation, community spaces, and other project-related interactions.

## Reporting

For security vulnerabilities, follow [SECURITY.md](SECURITY.md).

For conduct concerns, use a private contact channel provided by the repository owner rather than posting sensitive details publicly. If no private project contact is published yet, contact the repository owner through GitHub.

Project maintainers may edit, hide, lock, or remove contributions that violate these expectations and may restrict participation when necessary to protect the project or community.
